# Project conventions

- Always push finished work to `main` (not just the feature branch), unless the user says otherwise for that task.
- Keep code comments as low as reasonably possible. Only comment when the WHY is non-obvious (a hidden constraint, a subtle invariant, a workaround). Don't comment what the code already says through naming.
- For any section with left/right content (text vs. a visual), anchor each side to its own edge with real breathing room between them — not both sides clustered together with empty space left over on one edge. Use full-width `flex justify-between` (or equivalent) rather than a centered/capped container that squeezes both sides toward the middle.
